# loopForge v0.9.0 验收清单 — 核心约束

## 1. 版本范围与目标

本清单验收 **v0.9.0 核心约束** 能力（见 `doc/log/progress-v0.9.0.md`），补全 spawn 运行时核心约束。

| 能力 | 说明 |
|------|------|
| 非流式包装 | `wrapNonStream` 强制子 ChatModel 调用为 `stream=false`，trace/日志可见 `llm_mode=non_stream` |
| 级联取消 | 父 Run 终态时通过 `RunState.Terminate` 取消所有子 Agent；修复三个 ctx 盲点 |
| 全树预算共享 | `BudgetCounter` 结构体（tokens + USD），根 Run 持有、子树共享，超额返回 `SpawnError{Code: "budget_exceeded"}` |
| MaxConcurrentSpawns | 控制并发子数上限（默认 4） |
| engine 实装对接 | 完整实现 `Spawner` / `LoopPolicy` / `RunState` / `ChildRegistry` / `SpawnHandle` |

## 4. 集成验收：test-server（v0.9.0 手工 / 联调）

仓库 **`test-server/`** 依赖 `replace loopforge => ../loopForge`（已相应更新），用于在浏览器中验证 **spawn 相关表现**。

### 4.1 前置与启动

- Go 与 `test-server/go.mod` 一致；真实 LLM 需配置 `LARK_API_KEY` 等。
- 启动：`cd test-server && ./start.sh` 或 `go build -o ./bin/test-server . && ./bin/test-server`；默认 `ADDR` 为 `:8191`。
- spam 调试依赖真实 LLM 返回 spawn 工具调用。

### 4.2 spawn 调试验收项

| 验收项 | 通过标准 |
|--------|----------|
| spawn 工具调用 | 父 Agent 可调用 `spawn_subagent` 工具 |
| 子 Agent 非流式 | 子 Agent LLM 调用使用 `nonStreamModel`（日志可见 `llm_mode=non_stream`） |
| 子 Agent 隔离 | 子 Agent 事件不进入父事件流；子完成后结果正确回注 |
| 预算展示 | SSE 事件或 API 响应中可观测 Budget 信息（如需） |

### 4.3 边界（不阻塞 v0.9.0 版本通过）

- linger 生命周期暂不支持（v0.9.2 实现），当前返回 `SpawnRejected` + `Code="unsupported_lifecycle"`
- 工具白/黑名单过滤（v0.9.1 实现）
- spawn 事件 `EventSpawnStart/End/Wake`（v0.9.1 实现）

### 6.6 小结

- **主线（非流式包装、级联取消、预算共享、engine 实装对接）**：**代码已全部实现**，通过编译和 vet 检查，核心测试套件通过。
- **文档**：PRD、Plan、Progress 文档已创建（标记为"计划稿"），与实际代码实现状态不同步，需更新为"已完成"。
- **测试短板**：`internal/engine` 各模块、`pkg/model/nonstream.go`、`pkg/runtime/budget` **均无单元测试**。计划中的 13 项单元测试和 9 项集成测试均未实现。
- **设计注记**：`engineSpawner.Spawn` 中 handle 在子完成后注册并立即注销，观测窗口为零。实际级联取消依赖 `pkg/agent.spawn.go` 的 childCtx 机制而非 engineSpawner 的注册表。
- **预算默认值**：`SpawnBudgetTokenTreeDefault = 0`（无限制），需生产部署时按模型定价调整。

若需跟踪未完项，建议以 **v0.9.1 / v0.9.2** 补充测试覆盖，或在本版本提交前补充关键路径测试。
