## 验收命令

### 构建

```bash
# loopForge 主模块
cd loopForge && go build ./...

# test-server
cd test-server && go build ./...
```

### 单元测试

```bash
cd loopForge
go test ./pkg/mcp/...          # mapping + schema 单元测试
go test ./debug/...            # nil 防护测试（TestNilConnErrors 无需 env）
```

### 集成测试（需运行 SeRagLF MCP Server）

```bash
# 启动 seraglf（或其他 Streamable HTTP MCP Server），默认监听 :8080/mcp
cd loopForge
LOOPFORGE_SERAGLF_MCP_URL=http://127.0.0.1:8080/mcp \
  go test ./debug/... -v -run TestDialPingListCallStreamableHTTP
```

### test-server 本地联调

```bash
cd test-server

# 使用默认 seraglf 端点（http://127.0.0.1:8080/mcp，前缀 gmp__）
./start.sh

# 自定义 MCP 端点
LOOPFORGE_MCP_TEST_URL=http://my-mcp-server/mcp \
TEST_SERVER_MCP_PREFIX=myprefix__ \
  go run .

# 完全禁用 MCP
TEST_SERVER_DISABLE_MCP=1 go run .
```
